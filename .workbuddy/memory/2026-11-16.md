## 首次加载 bug 修复

- 通过 `Logs/General.log` 的 `[E][Lua]` 行定位错误（Errors 目录只有 GPU 崩溃 dmp，Lua 报错在 General.log）。
- 错误 1：无限服客户端 `GetBuildInfo()` 第 4 个返回值是字符串，直接与数字比较报 `attempt to compare number with string` → 统一 `tonumber(v)` 兜底。
- 错误 2：UI.lua 直接 `function ns.UI.xxx()` 但从未初始化 `ns.UI = {}` → 报 `indexed assignment on field 'UI' (a nil value)`。
- 教训：Core.lua 加载中途报错会中断该文件后续代码（slash 命令没注册，/wgm 无反应），排查看 General.log 而不是 Errors 目录。

## 第二轮：SetSmoothing("BOTH") 不合法

- 症状：窗口只有背景（shadow/panel 底/光斑），标题、卡片、按钮全无 → Build 在面板底之后的动画步骤抛错中断。
- 根因：这个客户端 `SetSmoothing()` 合法值只有 "IN_OUT"/"OUT"/"IN"/"NONE"，"BOTH" 直接抛错（对照现有插件全部用法统计确认）。
- 修复：全部换成 "IN_OUT"；Build 改为 SafeStep 分步 pcall，单步失败会在聊天框打印，避免"只剩背景"且无日志的盲区。
- 注意：General.log 日志流在第一次 /reload 后就死了（GameUI::Shutdown 关闭了写入），之后 Lua 报错不落盘，只能靠聊天框红字/界面观察。SavedVariables 确认插件加载成功（WOWGoldMaker.lua 已生成）。

## 第三轮修复（Scale 方法名 + 设置页 + 错误落盘）
- 「构建 Animations 失败」根因：客户端 Scale 动画方法是 `SetScaleFrom/SetScaleTo`（EllesmereUI 验证过），不是 `SetFromScale/SetToScale`（全客户端零使用）。
- 「设置打不开」根因：`Settings.OpenToCategory()` 要传 `category:GetID()`（数字），不能传类目对象（参考 BlinKii）。
- 「构建 Header 失败」根因未定位：SafeStep 用 print 输出不进 General.log，只显示在聊天框。
- 错误落盘方案：SafeStep/RefreshStats/设置页注册的 pcall 错误现在同时 `geterrorhandler()(msg)` 转发给客户端错误处理器 → General.log 会出现 `[E][Lua]` 记录；print 红字保留在聊天框。
- 诊断工具：`/wgm debug` 打印 refs/frame/GetMoney/UnitLevel 状态，区分卡片 `--`/`ERR` 两种信号。
- 金币/等级显示 `--` 的排查进行中，等用户 `/reload` 后反馈。

## 第四轮修复（C.white 缺失 = Header 失败 + 设置页失败共同根因）
- 日志证据（geterrorhandler 转发后首次落盘）：`Theme.lua:30: attempt to index local 'c' (a nil value)` ← Core.lua:74(BuildSettings pcall)
- 根因：配色表 `T.C` 缺失 `white` 键，但两处在用：
  - Theme.lua:246 `T.Checkbox` 未选中态 `c.white`
  - UI.lua:161 `BuildHeader` 分隔线 `T.Line(..., C.white, 0.08)` ← 这就是之前查不到的「构建 Header 失败」
- 修复：T.C 补 `white = {1,1,1}`；`T.rgb`/`T.hex` 加 type 守卫（非表时回落白色），以后键名笔误只会掉色不再炸整段构建
- 方法论沉淀：颜色键引用可用 `grep -oh "c\.[a-zA-Z]\+"` vs 配色表键做 comm 差集，快速定位未定义键。审 UI 报错时优先怀疑「nil 传给了颜色/贴图工具函数」而不是 API 不存在。

## 第八轮（金币图标"慢慢跑没了"）
- 症状：金币圆形图标开窗后逐渐飘走/消失，而锚在它上面的问候语文字不动。
- 根因：`Translation` + `SetLooping("BOUNCE")` 在该客户端每轮把 offset 累积叠加（不是往返）。coin 的 bob 是 (0,4)/3.2s → 每分钟上飘约 75px，几分钟出屏。Animation 只改渲染变换，不影响锚点，所以文字留原地 → 现象吻合。
- 同类隐患共 4 处：分隔线金色高亮 (340px/6.5s)、金币 bob (0,4)、glowA (30,12)/7s、glowB (-26,-10)/8s。
- 修复原则：循环动画只用**绝对值**类型（Alpha/Scale），它们每轮由 SetFrom/SetTo 重置，不会漂移。
  - accent → Alpha 0.35↔1.0 / 3.2s
  - coin bob → Scale 1↔1.05 / 3.2s
  - glowA/glowB → Alpha 0.05↔0.10 / 7s、0.04↔0.09 / 8s
- 规则沉淀：此客户端禁用「循环 Translation」，需要位移感就用 Scale/Alpha 替代。
